# 抖音下载浏览器

本地网页应用：给 E 盘那堆「UID_昵称_发布作品」文件夹套一层可浏览、可标注的界面。
技术栈 = Python `ThreadingHTTPServer` + 原生 HTML/CSS/JS，**无框架、无构建、无数据库、无 AI 依赖**。

- 地址：`http://127.0.0.1:8723`
- 数据源：`E:/dyyyyyyyyyyyyydownload/.../downnnnnnnn`（只读）
- 不可再生的数据只有一个：`data\user_data.json`（你的标注），其余都能重建

## 快速开始

双击 **`start-browser.bat`** 即可：
1. 若还没有 `data.json`，先全量扫描 `downnnnnnnn` 目录（约 1700 个文件夹，20 分钟上下；按钮上会显示进度）；已有则直接加载
2. 启动本地服务 `http://127.0.0.1:8723/`
3. 自动打开浏览器


## 功能

- **作者列表**：懒加载 + 搜索 + 排序；卡片上只显示名字、作品数和最新作品日期，不再显示 UID
- **「每作者一行」模式**：工具栏左侧的布局按钮可以在「网格卡片」和「每作者一行」之间切换。一行里是作者表头（名字、等级/频率/状态/标签、`⬇ N 天前` 最后下载、`N 个作品`）+ 一行作品卡片（**固定列数，不左右滑**，按窗口宽度算能放几张），右侧是常驻播放区 —— **点卡片就地播放**，不跳作者页。选哪种布局会记住，下次打开还是它
- **搜索（分范围）**：搜索框左边有个下拉，可选**全部 / 昵称 / 备注 / 简介 / 作品**，只在对应范围里找。其中搜「作品」时结果**直接是作品卡片**（缩略图 + 描述），点进去直接打开该作者主页并定位到那个作品。框里有关键字时右侧出现 **×** 一键清空。
- **刷新**：工具栏「⟳ 刷新」按钮——重读标注和统计数据、重拉列表第一页，**筛选/搜索/排序都保留**。数据集是别的程序在后台写的时候（下载器刚跑完、另一个标签页刚改过东西），点它比 F5 省事（F5 会丢掉筛选面板里还没提交的输入）。
- **排序**：下拉可选 9 项 —— 昵称 / UID / 作品数 / 视频数 / 图文数 / 最新作品 / 最早作品 / **添加顺序** / 作者等级；旁边「↑ 正序 / ↓ 倒序」按钮切换方向（每个字段有默认方向，如数量/日期/等级/添加顺序默认「大的新的在前」）。「添加顺序」= 作者文件夹的创建时间（什么时候下载进来的）。
- **筛选**：右上角「🔍 筛选」按钮点开一个面板，可以按 7 组条件叠加筛选作者 —— **SEC_UID**（有 / 没有）、**星标**（是 / 不是）、**最后更新时间**（最近 7 / 30 / 90 / 365 天，或**自定义起止日期**）、**作者等级**（夯 / 顶级 / 1级 / 2级 / 未设置，**可多选**）、**封面**（有 / 无）、**账号状态**（9 类，**可多选**）、**更新频率**（`day` / `3天` / `周` / `月` / 未设置，**可多选**）。点选即生效，设过筛选后按钮上会亮一个小圆点，「重置」一键清空。
- **作者详情**：点作者 → 内容区变成左右两栏。左栏是一整个可滚动的容器：返回栏 + 作者信息（UID、SEC_UID、主页简介、时间范围、状态、标签、备注、历史）+ 视频列表；右栏是固定的媒体预览/观看区
- **推送到待下载**：详情页 SEC_UID 那行的「获取资料」右边，可以把这位作者一键推进「待下载区」，之后在「导出作者信息 → ① 选作者」里直接勾他，不用回抖音再找一遍。重复推会提示「已经在里面了」
- **边翻边看**：左侧整块区域（返回栏 + 作者信息 + 视频列表）可以用滚轮单独上下滚，右侧媒体区固定不动；返回列表会回到你点进作者时的那个位置，返回栏右端有「↑ 顶部」
- **🆕 新下载**：侧边栏进入，只看「最近下载下来的那批文件」—— 数据来自下载记录库的文件写入时间，不是目录扫描，所以选「今天」就是真今天下的。左边一位作者一个气泡（气泡里横向排满作品卡），右边常驻播放区，点卡片就地看。**没有条数上限**，列表滚到底自动续页。
  - 顶栏有「筛选」，5 组条件（作者等级 / 标签 / 账号状态 / 更新频率 / 最后下载时间），每行行首一个圆钮：**＋ = 包含**（勾中的是我要的）、**－ = 排除**（勾中的去掉），和「导出作者信息」同一套用法。筛选在服务端做，翻页拿到的也全是筛完的结果
  - 卡片上的日期是**作品发布日期**（写成了 `发布 YYYY-MM-DD`），而上方时间范围切的是**下载日期**，两者常常差好几年 —— 所以「今天」里看到 2025 年发布的作品是正常的
- **作品分类**：顶部一行筛选按钮 —— `全部作品 / ▶ 视频 / 🖼 图文 / 单图 / 多图 / 单动图 / 多动图`。「图文」包含所有图和所有动图；「单动图」= 帖子里只有 1 段动图，「多动图」= 2 段以上。卡片上不额外打标记，看这一行的数字就知道各有多少。
- **带动图的作品**：有些帖子里除了清晰静态图，还夹着约 3 秒的动图（静态图就是动图暂停的那一帧，所以更清楚）。动图下载下来已经是视频文件，所以**就跟普通多图一样翻**：翻到静态图看图，翻到动图直接播放（带声音、自动循环），不需要点任何额外按钮。
- **账号状态**：下拉可选 `未设置 / 正常 / 私密账号 / 注销 / 禁言/封号 / 停更/偶更 / 卖号 / 不好看了 / 待修改`；卡片上的徽章按状态分色（正常绿 / 私密蓝 / 封号红 / 停更黄 / 卖号紫 / 注销深灰 / 不好看了青 / 待修改橙），没设置就不显示徽章。**不设置就是正常**，只有账号出问题时才需要改；设过之后作者卡片上会显示对应徽章
- **每个状态的说明**：侧边栏「分类」里点某个状态（私密账号/注销/禁言封号/停更偶更/卖号/不好看了/待修改）→ 标题右边出现一个单行输入框（和搜索栏一样，点一下就能写），写「我怎么理解这个状态」（判定标准），**每个状态各存一段**，停下 700ms 自动保存。写给自己看的，方便以后判断某个账号该归哪类
- **起个自己的叫法（别名）**：作者名旁边有个 ✎，点开填名字 —— 之后到处都显示「**你起的名字** + 灰色原昵称」，原昵称不会被改掉；输入框留空保存就恢复用原昵称。
- **标签**：点标签卡右上角「＋ 添加」→ 下拉列出所有已有标签（按用的人数排序），点一下就加上；没有想要的就在输入框里打新名字，回车即创建并添加。已经加过的不会重复添加。
- **左侧「大小号」入口**：侧边栏最上面 `🔗 大小号`（后面数字是组数）。进去后**一个大小号组 = 一个文件夹**，组里的账号都收在同一个文件夹里：
  - 点文件夹标题展开/收起；点 ✎ 给文件夹改名；点「解散」解除这一组的关联（只断关系，不删账号和文件）
  - 点某个账号直接进它的详情页，「← 返回列表」会回到这个大小号页面
  - 以后新关联了账号，这个页面**每次进来都会重新读**，文件夹自动更新
- **大小号关联（多向）**：详情页「大小号」横条里点「＋ 新增」会弹出**账号搜索框**，搜的是**账号本身**：备注 / 昵称 / 抖音号 / UID / sec_uid / 作者简介（**不搜作品**，所以不会冒出一堆只是在作品里提过这个词的陌生人），点「关联」即生效。
  关联之后**整组互相关联**——A 关联了 B、C、D，那么从 B 的页面也能直接看到 C、D。
  - 标题的「大小号（组内 5）」= 这一组一共 5 个账号（含当前这个），下面只列另外 4 个。
  - 组内账号一律显示**昵称**；昵称重复时后面补作品数（如 `kitt霓（221）`）。鼠标悬停可看 UID。成员 pill 点一下直接进它的主页（右边没有 ×，解除统一走横条右侧的「解除关联」）。
  - **设为大号 / 取消大号**：一组里只能有一个「大号」。横条里的按钮在**不是大号**时显示「设为大号」，**已经是大号**时显示「取消大号」（点一下取消）。设/取消大号都**同步整组**。大号在列表和文件夹里只带一个轻量「大号」小标记。
  - **解除关联**（横条最右，橙色）：解除当前账号和组内其他所有人的关联（其余人之间互相关联不受影响）。
  - 关联搜索框顶部还有两个按钮：**「解除本号全部关联」**（把当前账号从它所在组里整个摘出来）和 **「➕ 新建作者」**（粘一个新作者的主页链接，自动去掉 `?from_tab_name=…&vid=…` 之类多余参数、自动查 UID、拉昵称/抖音号建档，并和当前账号关联）。
- **导出 SECID**：作者列表右上角「排序」旁边有个「📤 导出 SECID」按钮，把**当前界面**的作者（含每个账号所在大小号组的全部成员）的 SEC_UID 导出成一个 txt，每行一条 `https://www.douyin.com/user/…` 完整链接，存到 `export/` 文件夹（文件名 = 类型 + 时间，同名自动加后缀不覆盖）。星标和标签视图会自动排除「注销 / 禁言封号 / 卖号 / 不好看了」的账号，单独看某个状态列时则原样导出。
- **🗑 作品多选删除（移入回收站）**：进作者详情页，返回栏最右边的 🗑 → 点作品打勾 → 「**移入回收站**」。文件搬到 `browser\recycle-bin\<批次>\`、索引同步、作品数减少，网页里立刻不显示；**后悔了到「文件管理 → 回收站」点「恢复」**，搬回原位、作品重新出现。确认不要了再点「彻底删除」才真删。每次操作都记在 `data/删除记录.jsonl`（含批次号）。
- **📁 文件管理**：侧边栏「功能」里。上半是**文件夹改名**——把「文件夹名」改成「你标注的昵称」；支持单个改、搜索过滤、一键全部改，改完自动同步索引，不用重扫。名字里带 `: > < *` 或结尾带点的会自动洗掉这些字符再改；洗完跟现有文件夹名一样的不再列出。中间是**重复作品清理**——按作者点「逐份比较」展开，每条作品一排两个气泡（在用 / 隔离区副本），各自带缩略图、大小、文件名，气泡下面一个圆圈选「保留这份」，选完按右上角「删除重复」执行。最下面是**回收站**——删掉的作品都在这儿，一批一行，可以「恢复」或「彻底删除」。
- **💗 获取最近收藏**：侧边栏「功能」里点开是一整个页面。选**来源**（收藏 / 喜欢）和**条数**（横排胶囊按钮），点「开始获取」，几秒到几十秒出结果。结果按三个分类横排显示 —— **🆕 未下载过 / ✅ 下载过 / 🚫 黑名单**，点标签切换。
  - 每行显示「**最新发布** X · **本地已存** Y」：X 是该作者在抖音上最新的作品时间，Y 是你电脑里存的最新作品日期，后面用颜色标出差多少天 —— 红「缺 N 天」（抖音有新的你没存）、绿「已同步」、蓝「本地超前 N 天」（抖音那边可能删了/设私密）、灰「本地未存」。
  - 还会标「**该收藏作品已下载 / 未下载**」，直接看出这条被收藏的作品本地有没有。
  - 已下载的作者**点名字**能直接进他的本地主页，返回时仍在收藏页、滚动位置不丢。
  - 未下载 / 黑名单里的作者，「＋ 黑名单」一键加进去，下次就不会再烦你。
  - 抓取结果切到别的页面也不会清空，想清空点页头「🗑 清空」。
  - 「最新发布」这列的时间有两种口径可选：用**收藏那条作品的发布时间**（快，不额外请求），或去**该作者主页查真正的最新作品**（准，但每个作者多一次请求）——在设置里改。
- **🚫 黑名单**：侧边栏「分类」里的独立整页。一行一个账号：昵称 / UID / 原因 / 加入时间 / 抖音主页链接 / 操作。
  - **＋ 添加账号**：粘一条抖音主页链接，自动查出 UID 和昵称再入册。
  - **原因用标签**：点原因可以多选已有标签，也可以自己打新的（如「卖号」「公司号」「音乐合集太长太大」），一个账号能挂多条；标签后面的 × 单独删掉某条。
  - **进了黑名单的作者，浏览列表/搜索/统计里直接不再出现**（磁盘上的文件和文件夹原样保留，随时能从名单里移除再回来）。
- **📤 导出作者信息**：侧边栏「功能」里，选**等级 / 标签 / 账号状态 / 更新频率**（都能多选）→ 预览命中数量和名单 → 导出 CSV 到 `export/`。
- **⚙️ 设置**：侧边栏「功能」里。
  - **更新频率禁用状态**：勾掉的状态（注销 / 禁言封号 / 卖号 …）不参与「更新频率」，保存时会把已经设过频率的这些账号**真正清空频率**，不只是显示上灰掉。
  - **最新发布口径**：收藏页「最新发布」那列取哪个时间（已收藏那条的发布时间 / 只查已下载作者主页 / 所有作者都查主页）。
  - **地址**：数据库目录、FFmpeg、DouK 组件目录，显示当前生效值，点「修改」才能编辑（改错会让转码/抓收藏失效，不确定就别动）。
  - **缓存**：两组缓存（🖼 缩略图上限 3 GB / 🎬 转码上限 300 MB）的占用和清理按钮，**不碰封面**。
  - 底部「保存 / 取消」常驻屏幕最下方；没改动时保存是灰的。
- **标签 / 分类**：手动打标签（下拉选已有或新建），侧边栏按标签筛选
- **星标**：详情页左下角一个星形按钮 —— 灰色描边是没标，点一下变金色实心（已标），再点取消。列表卡片和侧边栏计数都会跟着变
- **封面**：播放/看图时点「🖼 设为封面」，视频自动截一帧；设完作者列表的卡片也会跟着变
- **⛶ 填满**：竖屏视频两侧有黑边时，点它可以裁切铺满整块画面（会切掉一点边缘），再点一次恢复「适应」
- **获取资料**：点作者信息区的「获取资料」，会从抖音拉昵称/抖音号/简介。
  - **原来是空的字段** → 直接把值补上，不打扰你。
  - **已经有值的字段**（跟抖音不一样）→ 弹一个小窗，列出「旧值 → 新值」，你自己选：**只换昵称 / 只换抖音号 / 只换简介 / 全部替换 / 取消**。
  - 用的是登录态接口，**简介能拿到**（之前公开接口把简介返回成空串，才会一直显示「未填写」）。
- **🧰 批量获取资料**：侧边栏「功能」里点开是**一整个页面**（跟「大小号」一样整页切换，不是弹窗）。按页头的「开始获取」就交给**后台**去跑（1500 个账号约 15 分钟）。
  页头下面有三组设置：**获取内容**（昵称 / 抖音号 / 简介，默认全勾）、**跳过**（禁言/封号、注销默认跳过——主页打不开或 404，查了白查还会触发限流；私密账号可选）、**顺序**（默认「添加时间 新→旧」，另有旧→新 / 作品数 / 最近更新 / 最早发布 / 昵称）。右边实时显示「共 N 个 · 本次将获取 M 个（跳过 K 个）」。设置会记住，下次进来还是上次的。
  - 跑起来后可以切到别的页面继续浏览，**甚至关掉网页**（服务不停任务就不停）；侧边栏那行会显示 `35/1500` 实时进度。
  - 跑完会提示，页面上显示这次补全了多少、多少条要你确认、多少条没取到（失败清单可以点开看每个账号的原因）。关掉网页再进来也照样能看到。
  - 空字段（简介、本地没填的抖音号）直接补上。
  - **昵称或抖音号跟本地不一致的，一律先不改**，攒成「待确认」清单（侧边栏该项后面有数字角标，刷新页面也不会丢）。
  - **昵称和抖音号都对不上**的会标黄「可能 SEC_UID 指到了别的账号」，这种整条都不会写，连简介都不补。
  - **已经起了备注（别名）的账号不会因为改名来烦你**：显示用的是备注，所以昵称直接换成抖音上的，备注一个字都不动。
  - 每条卡片上都能点「↗ 进主页」或直接点账号名，跳到这位作者的主页（看作品、查 SEC_UID）；返回时回到批量页原来的位置。
  - 顶部统计那四个数字**都能点**：点「失败 N」只看没取到的、点「补全 N」看这次补了谁改了哪些字段、点「待确认」看卡片、点「共」一起看。
  - 每条可以选：**用新昵称 / 用新抖音号 / 全部采用 / 忽略**（「全部采用」会把简介一起写入）。
  - 跑一半想停就点面板里的「停止」，已查到的照样保存。
- **SEC_UID**：没有时显示「＋ 填写」；有值时显示成一段抖音主页地址（`https://www.douyin.com/user/MS4wLjAB…`），点一下就打开真正的个人主页，鼠标悬停能看到完整地址；旁边是「更改」「获取资料」。
  填的时候**可以直接把浏览器地址栏整条网址粘进去**（`https://www.douyin.com/user/MS4w…`，带 `?vid=` 之类参数也行），会自动取其中的 SEC_UID 存下来；粘 `v.douyin.com` 的短链接不行，会提示你换主页地址。
- **历史记录**：默认只显示最近 2 条，点标题右边的「全部 ▾」展开全部，可编辑 / 删除 / 手动加一条；扫描时发现改昵称会自动记录旧名，你自己改别名也会记一条

> 说明：`douyin_id`、`signature` 扫描时取不到，只有 `sec_uid` 能从 `Data/*.xlsx` 拿到（663 份表）；其余靠 `tools/legacy/import_secuid.py`（本机资料）、`tools/fill_secuid_from_export.py`（**本地导出表，秒级**）、`tools/legacy/fetch_uid_by_secuid.py`（联网 sec_uid→uid）和 `tools/legacy/fill_missing_secuid.py`（联网 uid→sec_uid 反查）补进 `user_data.json`，当前合计 **1753/1758**（仅剩 5 个已注销/封禁/私密账号无法补）。`cover`（封面）通过播放区的「🖼 设为封面」按钮设置，视频自动截一帧、图片取原图。
